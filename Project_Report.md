
# Project Report

# Weather Meets Pollution:
## An Exploratory Data Analysis of Weather Conditions
## and Air Quality Across Indian Cities

## 1. Introduction

Air pollution is an important environmental concern.

This project focuses on exploring weather conditions
and air quality across different cities in India.

The analysis uses Python libraries to understand
pollution patterns and relationships between
weather variables and PM2.5 levels.

## 2. Problem Statement

The objective is to analyze air pollution patterns
across Indian cities and explore how weather
conditions are statistically related to PM2.5 levels.

## 3. Project Objectives

- Analyze air quality across Indian cities.
- Identify cities with higher and lower average PM2.5.
- Study monthly pollution patterns.
- Explore weather and pollution relationships.
- Create meaningful visualizations.

## 4. Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 5. Methodology

Step 1: Data Collection

Collected weather, air quality, and city information
from the selected dataset.

Step 2: Data Exploration

Examined rows, columns, data types, and missing values.

Step 3: Data Cleaning

Step 4: Data Merging

Combined relevant datasets using appropriate keys.

Step 5: Exploratory Data Analysis

Performed city-wise, monthly, and statistical analysis.

Step 6: Data Visualization

Created charts to understand pollution patterns
and relationships between selected variables.
